# Student Result Analyzer — ScholarDesk

## Project Overview

ScholarDesk is a Python-based Student Result Analyzer developed to manage student records and analyze academic performance through a simple web interface.

## Features

* Student registration and login
* Add, view, edit, and delete student records
* Input validation for student details and marks
* Automatic calculation of total marks and percentage
* Grade and Pass/Fail analysis
* Dashboard with academic statistics
* Search, sorting, and pagination
* CSV export
* Dark mode and customizable settings
* SQLite database for storing student records
* Error handling for invalid inputs and operations

## Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS
* JavaScript

## Python Modules

* `app.py` — Flask application and API routes
* `database.py` — Database operations
* `validation.py` — Input validation
* `result.py` — Result calculations and analysis

## Project Workflow

1. The user logs in or creates an account.
2. Student details and subject marks are entered.
3. The application validates the provided information.
4. Student records are stored in the database.
5. The application calculates total marks, percentage, grade, and result status.
6. Dashboard and analytics display academic performance.
7. Student records can be updated, deleted, or exported.

## How to Run

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal in the project directory.
4. Install the required dependencies using the project's `requirements.txt`, if available.
5. Run the Flask application using the command specified by the project.
6. Open the local URL displayed in the terminal.

## Testing

Test the application with valid and invalid student details, different marks, login/logout, student record operations, result calculations, and CSV export.

## Project Objective

The objective is to apply Python development concepts, including modular programming, input validation, data processing, database operations, and error handling, in a practical project.
